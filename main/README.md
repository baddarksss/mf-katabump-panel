# سورس اصلی M&F (بایگانی)

این پوشه نسخهٔ اصلی و دست‌نخوردهٔ سورس قبلی است که اول کار در اختیار ما قرار گرفت. برای اجرا یا نصب نسخهٔ جدید از آن استفاده نکنید؛ نسخهٔ جاری در ریشهٔ ریپو است.

- `index.js` — همان فایل اصلی، بایت‌به‌بایت بدون تغییر. شناسهٔ نسخهٔ داخل آن `mf-panel-katabump-1.1` است و پورتال کاربر و ثبت‌نام داخل خودش دارد. SHA256: `17627aa1b6b12b3401771a1839d4bd1cb98afff22f0feae798be83a9edfa562a`
- `package.json` — بازسازی از روی همان فایل (نام، نسخه و فرمان اجرا). نسخهٔ اصلی هیچ وابستگی خارجی ندارد.
- `ORIGINAL-SHA256.txt` — اثر انگشت فایل اصلی برای بررسی سلامت.
- `README.md` — همین توضیح.

اگر فایل چهارم بستهٔ اولیه چیز دیگری بود (مثلاً یک راهنما یا فایل تصویر)، همان را هم می‌شود کنار این‌ها گذاشت؛ تنها فایلی که از آن بسته باقی مانده بود `index.js` است.
